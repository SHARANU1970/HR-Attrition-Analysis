# HR Attrition Analysis

Analyzed **1,500 employee records across 35 variables** using Python (Pandas) to identify potential drivers of employee attrition.

## Objectives
- Identify attrition patterns by department and salary band.
- Evaluate overtime, satisfaction, work-life balance, travel, tenure and distance as potential attrition factors.
- Clean missing data and prepare KPI outputs for HR reporting.
- Support Power BI visualization and stakeholder decision-making.

## Data Quality
- Records: **1,500**
- Variables: **35**
- Missing cells before cleaning: **535**
- Missing cells after cleaning: **374**
- Missing-data reduction: **30.1%**

## Tools
**Python, Pandas, NumPy, Matplotlib, Power BI**

## Files
- `hr_attrition_raw.csv` — raw synthetic data with missing values.
- `hr_attrition_clean.csv` — cleaned analysis dataset.
- `HR_Attrition_Analysis.xlsx` — Excel KPI summaries.

> This is synthetic portfolio/demo data, not real employee or company HR data.
