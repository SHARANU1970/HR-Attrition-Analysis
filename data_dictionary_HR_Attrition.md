| Gender | Employee gender |

| Job_Role | Employee job role |

| Education | Education category |

## Data Note
This is synthetic portfolio/demo data. Missing values in the raw file are intentionally introduced for cleaning practice. The clean file uses standard imputation while retaining a controlled residual missingness level.
